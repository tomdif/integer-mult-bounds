# Current refit dispatcher: whole words, rows and return boundaries

**Scoped written proof; the full multiplication theorem remains incomplete.**
This continues the proof-completion request for the paired terminal refit. It
does not change the selected frontier or claim a new numerical saving.

[PROOF.md](PROOF.md) constructs a dispatcher for the current 73-dimensional,
66304-family program. The main simplification is to expand the fixed finite
orthogonal cover into permanent packet roles. This is an enormous but
input-independent tape inventory. It makes owner selection explicit and gives
each child its complete packet of volume `V/(66304 Gamma)`. The proof supplies
row splitting, current opcode lowering, phase-coordinate conventions, local
parking, descriptor restoration, and the node cost needed by the previous
weighted induction. It composes the credited B1/compact routines and native
algebraic certificates; it is not a new formal machine proof.

The executable evidence includes:

* All four native invocations (two providers, both directions): 22353 events
  each, lowered to 29305 primitives and executed exactly over Gaussian dyadics
  on all 512 addresses of 632 live packets. An independent endpoint calculation
  uses the original convolution kernels. All 82 zero buffers and eight centres
  clear. The reported numerical maxima are observed at primitive boundaries,
  not claims about every arithmetic scratch value or every possible input.
* All 420912 current owner occurrences, 10339 distinct complete charts, all
  2222 global events, and the actual hosted-axis/idle-rank accounting.
* 4256 exact phase-polynomial identities, each covering all `2^73` frequencies
  by coefficient comparison. The 20032 zero-rank nonzero translations remain.
* Literal four-symbol tape movement through recursive row splitting, parking,
  call, merge and return. These tests use complement leaves and explicitly
  test independence from ancestor contents and stack offset. They replace the
  predecessor's abstract row-routing shims; they do not execute an entire
  numerical native word at the microtransition level.

Mutations remove a real warp, reverse a residual adapter, omit a buffer release,
drop global bridges, reverse physical scatter and violate complete rows. They
must be rejected. [RESULT.json](RESULT.json) is compared in full in both modes:
